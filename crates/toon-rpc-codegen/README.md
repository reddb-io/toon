# toon-rpc-codegen

Code generator for TOON-RPC. Parses IDL files (`.toonrpc`) and generates Rust and TypeScript code.

## Usage

```bash
# Generate both Rust and TypeScript
toon-rpc-gen service.toonrpc --both

# Generate only Rust
toon-rpc-gen service.toonrpc --rust

# Generate only TypeScript
toon-rpc-gen service.toonrpc --ts
```

## IDL Format

`.toonrpc` files are written in TOON format. Example:

```toon
version: "1.0"
service: "Calculator"
types:
  Vec2:
    x: f64
    y: f64
methods[2]{name,params,result}:
  add,"\"a\":\"f64\",\"b\":\"f64\"",f64
  subtract,"\"a\":\"f64\",\"b\":\"f64\"",f64
```

## Type System

| Type | Rust | TypeScript |
|------|------|------------|
| `i8`/`i16`/`i32`/`i64` | `i8`/`i16`/`i32`/`i64` | `number` |
| `u8`/`u16`/`u32`/`u64` | `u8`/`u16`/`u32`/`u64` | `number` |
| `f32`/`f64` | `f32`/`f64` | `number` |
| `bool` | `bool` | `boolean` |
| `string` | `String` | `string` |
| `bytes` | `Vec<u8>` | `Uint8Array` |
| Custom types | `struct`/`enum` | `interface`/`type` |
